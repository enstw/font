FONTLOG for ENS Font (Elegant Nerd Sino)

This file provides detailed information on the ENS Font Software.
This information should be distributed along with the ENS Font fonts
and any derivative works.

---

Basic Font Information

ENS Font is a merged terminal font combining:
  - LXGW WenKai TC / WenKai Mono TC (all text glyphs incl. ASCII/Latin/CJK, SIL OFL 1.1)
  - Symbols Nerd Font (PUA icons, MIT)

The merge is automated via GitHub Actions and tracks upstream releases.

Reserved Font Names: "ENS Font" and "Elegant Nerd Sino".

Change Log

2026-07-24 (v4.0.0) - Pure LXGW text, symbols-only donor
  - Removed Atkinson Hyperlegible Next and Meslo LGSDZ donors entirely
  - ASCII/Latin now retained from LXGW WenKai TC / WenKai Mono TC
  - PUA icons transplanted from Symbols Nerd Font (Mono flavor for strict mono)
  - Mono grid moved from 600/1200 to LXGW's native 500/1000
  - Vertical metrics now kept from the LXGW base (no donor metric adoption)
  - Block elements / box drawing rescaled to fill the hhea cell

2026-03-24 (v3.1.9) - Diagnostic & Testing Tools
  - Added utils/analyze_font_metrics.py: Analyze font vertical metrics and
    block element coverage.
  - Added utils/gen_cell_test_fonts.py: Generate font variants with custom
    cell heights for testing terminal gap behavior.

2026 (v3.0.0) - Meslo LGSDZ donor switch
  - Base: LXGW WenKai Mono v1.521
  - ASCII/PUA: Meslo LGSDZ Nerd Font v3.4.0
  - Donor precedence: Meslo LGSDZ > LXGW WenKai
  - OS/2 metrics aligned to Meslo LGSDZ for terminal compatibility
  - Added "ENS Font Mono Prop" variant for Ubuntu Terminal (proportional PUA)
